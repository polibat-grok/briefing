📞 클로옵스 070 번호로 걸려 온 전화를 그록이 받고, 요약은 텔레그램으로

결론
  • 길은 하나예요. 클로옵스가 070 전화를 그록 주소(SIP)로 그대로 넘기고, 그록이 통화합니다. 내 서버는 "전화 왔어요" 알림만 받아서 말투를 정하고, 끝나면 요약을 보냅니다.
  • 클로옵스 공식 문서에 OpenAI·ElevenLabs로 넘기는 예시가 있어요. 그록은 목록에 없지만 방식이 거의 같아서 될 가능성이 높습니다. 미확인
  • 필요한 것: 클로옵스 계정과 070 번호, 「SIP 트렁크 연결」 부가서비스, xAI API 키, 내 맥과 ngrok, 텔레그램 봇.
  • 비용: 그록 1분 약 107원 + 클로옵스 받는 전화는 요금제 포함. 다만 SIP 부가서비스가 월 99,000원일 수 있어요 미확인.

0. 그림 한 장

  1. 누가 내 070 번호로 전화
  2. 클로옵스가 그 전화를 sip:+8270…@sip.voice.x.ai(그록)로 넘김
  3. 그록이 내 서버로 "전화 왔어요(realtime.call.incoming)" 알림
  4. 내 서버가 그 통화에 접속해서 한국어 말투·안내 문구를 지정 → 그록이 대화
  5. 끊기면 내 서버가 대화 원문을 그록에게 요약시켜 텔레그램으로 전송

음성 자체는 클로옵스와 그록이 직접 주고받아요. 내 서버는 지시와 기록만 맡아서 코드가 짧습니다.

src/index.ts (전체)

import "dotenv/config";
import express from "express";
import crypto from "node:crypto";
import WebSocket from "ws";

const KEY = process.env.XAI_API_KEY!;
const SECRET = process.env.XAI_WEBHOOK_SECRET!;
const TG = process.env.TELEGRAM_BOT_TOKEN!;
const CHAT = process.env.TELEGRAM_CHAT_ID!;
const MODEL = process.env.XAI_TEXT_MODEL || "grok-4.3";

const INSTRUCTIONS = `너는 일론 김 대표의 전화 비서야. 한국어로 짧고 공손하게 말해.
첫마디는 반드시: "안녕하세요, 김 대표 비서입니다. 이 통화는 AI가 받고 내용이 기록·요약됩니다."
그다음 이름, 용건, 회신 받을 연락처를 차례로 물어봐.
모르는 건 지어내지 말고 "대표님께 전달해 회신드리겠습니다"라고 해.
다 들었으면 내용을 한 번 확인하고 인사로 마무리해.`;

// ① 서명 검증 (webhook-id / webhook-timestamp / webhook-signature)
function verify(raw: string, h: any): boolean {
  const id = h["webhook-id"], ts = h["webhook-timestamp"], sig = h["webhook-signature"];
  if (!id || !ts || !sig) return false;
  if (Math.abs(Date.now() / 1000 - Number(ts)) > 300) return false; // 5분 넘은 요청 거부
  const key = SECRET.startsWith("whsec_")
    ? Buffer.from(SECRET.slice(6), "base64") : Buffer.from(SECRET);
  const expected = crypto.createHmac("sha256", key)
    .update(`${id}.${ts}.${raw}`).digest("base64");
  return String(sig).split(" ").some(s => {
    const v = s.split(",")[1] ?? s;
    return v.length === expected.length &&
      crypto.timingSafeEqual(Buffer.from(v), Buffer.from(expected));
  });
}

// ② 통화 접속 + 받아쓰기 모으기
function joinCall(callId: string, from: string) {
  const lines: string[] = [];
  const started = Date.now();
  let bot = "";
  const ws = new WebSocket(`wss://api.x.ai/v1/realtime?call_id=${callId}`,
    { headers: { Authorization: `Bearer ${KEY}` } });

  ws.on("open", () => {
    ws.send(JSON.stringify({ type: "session.update", session: {
      voice: "eve",
      instructions: INSTRUCTIONS,
      turn_detection: { type: "server_vad" },
      audio: { input: { transcription: {
        model: "grok-transcribe", language_hint: "ko",
        keyterms: ["정치방망이", "립보기", "김 대표"] } } },
    }}));
    ws.send(JSON.stringify({ type: "response.create" })); // 그록이 먼저 인사
  });

  ws.on("message", (d) => {
    const e = JSON.parse(d.toString());
    if (e.type === "response.output_audio_transcript.delta") bot += e.delta ?? "";
    if (e.type === "response.done" && bot) { lines.push("그록: " + bot); bot = ""; }
    if (e.type === "conversation.item.input_audio_transcription.completed")
      lines.push("상대: " + e.transcript);
    if (e.type === "error") console.error("[xai]", e);
  });

  ws.on("close", () => { if (bot) lines.push("그록: " + bot); report(from, lines, started); });
}

// ③ 끊기면 요약 → 텔레그램
async function report(from: string, lines: string[], started: number) {
  const transcript = lines.join("\n") || "(대화 없음)";
  let summary = "(요약 실패)";
  try {
    const r = await fetch("https://api.x.ai/v1/chat/completions", {
      method: "POST",
      headers: { Authorization: `Bearer ${KEY}`, "Content-Type": "application/json" },
      body: JSON.stringify({ model: MODEL, messages: [
        { role: "system", content: "전화 기록을 한국어로 요약해. 발신자/용건/요청/연락처/후속조치 각 1줄." },
        { role: "user", content: transcript } ] }),
    });
    const j: any = await r.json();
    summary = j.choices?.[0]?.message?.content ?? JSON.stringify(j).slice(0, 300);
  } catch (e) { console.error(e); }
  const min = ((Date.now() - started) / 60000).toFixed(1);
  const text = `📞 ${from} · ${min}분\n\n🧾 요약\n${summary}\n\n💬 원문\n${transcript}`;
  for (let i = 0; i < text.length; i += 4000)
    await fetch(`https://api.telegram.org/bot${TG}/sendMessage`, {
      method: "POST", headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ chat_id: CHAT, text: text.slice(i, i + 4000) }) });
}

const app = express();
app.get("/health", (_q, s) => s.json({ status: "ok" }));
app.post("/xai/sip-webhook", express.raw({ type: "*/*" }), (req, res) => {
  const raw = (req.body as Buffer).toString("utf8");
  if (!verify(raw, req.headers)) return res.status(400).send("bad signature");
  const ev = JSON.parse(raw);
  if (ev.type === "realtime.call.incoming") {
    const from = ev.data.sip_headers?.find((h: any) => /^from$/i.test(h.name))?.value ?? "?";
    console.log("전화 옴", ev.data.call_id, from);
    joinCall(ev.data.call_id, from);
  }
  res.sendStatus(200);   // 빨리 200 응답
});
app.listen(Number(process.env.PORT ?? 8000), () => console.log("ready"));
미확인 4가지는 아직 직접 돌려 보지 않았어요.
  • 서명 방식: xAI 문서에는 헤더 이름 3개만 나와 있어요. 위 코드는 업계 표준 방식(Standard Webhooks)으로 가정했습니다. 계속 400이 나면 잠깐 검증을 끄고 로그로 확인하세요.
  • OpenAI는 통화를 받으려면 accept 호출이 필요한데, xAI 문서는 WebSocket 접속만 안내해요. 접속해도 전화가 안 받아지면 이 부분을 의심하세요.
  • 상대방 말 받아쓰기 완료 이벤트 이름(…transcription.completed)은 OpenAI와 같다고 가정했어요.
  • 요약 모델 grok-4.3은 xAI 모델 목록에 있는 이름이에요. 콘솔 Models에서 한 번 확인하세요.

4. 내 070 번호를 xAI에 등록 (1번만)

터미널에 붙여 넣으세요. 번호는 +82 뒤에 0을 뺀 형태로 씁니다(070-1234-5678 → +827012345678).

curl -X POST https://api.x.ai/v2/phone-numbers \
  -H "Authorization: Bearer xai-여기에키" \
  -H "Content-Type: application/json" \
  -d '{
    "origin": "byo_trunk",
    "name": "clawops-070",
    "phone_number": "+827012345678",
    "webhook": { "name": "my-webhook",
      "url": "https://elon-call.ngrok-free.app/xai/sip-webhook" },
    "sip_auth": { "allowed_addresses": ["34.47.65.45/32"] }
  }'
  • 응답에 나오는 signing secret을 .env의 XAI_WEBHOOK_SECRET에 넣고 서버를 다시 켜세요. 딱 한 번만 보여 줍니다.
  • 34.47.65.45는 클로옵스가 공개한 SIP 신호 서버 주소예요. 연결이 거부되면 sip_auth 줄을 빼고 다시 시도해 보세요. 시험할 때만 그렇게 하세요. 미확인
  • 잘못 등록했으면 GET /v2/phone-numbers로 id를 찾아 DELETE /v2/phone-numbers/{id}로 지우면 됩니다.
미확인 xAI가 한국 번호(+8270…)를 등록해 주는지, 번호 형식을 +827012345678로 받는지는 실제로 해 봐야 알아요. 에러가 나면 에러 문구를 보내 주세요.

증상의심 지점해볼 것
신호만 가다 끊기고 로그가 없음클로옵스→그록 연결 실패User 번호가 4단계와 같은지, Port 5061·TLS인지 확인. 클로옵스 통화 기록의 실패 사유를 캡처해서 보내기

8. 클로옵스에 물어볼 것

  1. 「SIP 트렁크 연결」로 070 수신 전화를 xAI(sip:+8270…@sip.voice.x.ai:5061;transport=tls)로 넘길 수 있나요? 해 본 고객이 있나요?
  2. 그 부가서비스가 가격표의 「SIP 직접연결 월 99,000원」과 같은 상품인가요? Trial·Individual에서도 쓸 수 있나요?
  3. 외부 SIP로 보낼 때 나가는 IP(신호·음성)는 무엇인가요? xAI 허용 목록에 넣으려고요.
  4. Request-URI에 번호를 E.164(+8270…)로 실어 보낼 수 있나요?
  5. 코덱은 G.711 μ-law/A-law를 쓰나요? xAI는 G.711·G.722를 받아요.

9. 안 되면: 다른 길 두 가지

  • 클로옵스 Stream: 클로옵스가 음성을 WebSocket으로 내 서버에 보내 주는 기능(<Connect><Stream>, G.711 μ-law)이 있어요. 내 서버가 그 음성을 그록과 이어 주면 됩니다. 부가서비스가 필요 없을 수 있지만, 코드는 SIP 방식보다 깁니다.
  • Twilio 미국 번호: 서류 없이 오늘 바로 되는 방법이에요. xAI 공식 예제가 그대로 돌아갑니다. 단점은 번호가 미국 번호라 국제전화로 걸어야 한다는 점이에요. 체험 계정은 인증한 번호에서 건 전화만 받습니다. 이전 Twilio 설명서를 따라 하시면 돼요.
