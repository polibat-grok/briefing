📞 내 전화를 그록이 받고, 끝나면 요약이 텔레그램으로 오게 만들기

결론
  • 오늘 하루면 됩니다. 필요한 건 xAI API 키 · Twilio 미국 번호 · 내 맥 + ngrok 세 가지.
  • xAI 공식 예제(Twilio Media Streams 방식)를 그대로 쓰고, "통화 끝나면 원문+요약을 텔레그램으로" 부분만 30줄 추가합니다.
  • 비용: 10분 통화 ≈ $0.89(약 1,190원) + 번호 월 약 $1.15(약 1,540원).

왜 이 방법(Media Streams)인가

✅ 공식 예제 (Media Streams)SIP 직결
설정번호에 웹훅 주소 1줄SIP 트렁크 생성 + xAI에 번호 등록 API + 서명 검증

장점오늘 바로 됨음질·지연 조금 유리, 키패드(DTMF)·전환 지원

→ 지금은 Media Streams로 시험. 정식 콜센터 때 SIP(sip:{번호}@sip.voice.x.ai;transport=tls)로 옮기면 됩니다. 어차피 둘 다 내 서버는 필요해요.

0. 그림 한 장

  1. 누가 Twilio 번호로 전화
  2. Twilio → 내 맥(ngrok 주소)으로 음성 실시간 전달
  3. 내 맥 → 그록 음성(wss://api.x.ai/v1/realtime)이 대화
  4. 끊기면 → 대화 원문을 그록 텍스트 API로 요약 → 텔레그램 전송

1. 가입 3곳 (20분)

① xAI 콘솔

  • console.x.ai 로그인 → Billing에서 크레딧 $10(약 13,370원) 충전
  • API Keys → Create → xai-... 복사해 메모

  • 체험 계정에서도 번호 1개 받을 수 있어요(체험 크레딧에서 차감).

③ 텔레그램 봇 (결과 받을 곳)

  • 텔레그램에서 @BotFather → /newbot → 토큰 복사
  • 만든 봇에게 아무 말이나 보낸 뒤, 브라우저로 https://api.telegram.org/bot<토큰>/getUpdates 열기 → "chat":{"id":숫자 의 숫자가 CHAT_ID

5. 추가 코드: 끊으면 원문+요약을 텔레그램으로

Claude Code에 이렇게 말하세요: "아래 코드를 src/report.ts로 만들고, index.ts의 media-stream 핸들러에 3군데 연결해줘."

// src/report.ts
const XAI = process.env.XAI_API_KEY!;
const TG = process.env.TELEGRAM_BOT_TOKEN!;
const CHAT = process.env.TELEGRAM_CHAT_ID!;
const MODEL = process.env.XAI_TEXT_MODEL || "grok-4-fast-non-reasoning";

export async function sendReport(lines: string[], startedAt: Date) {
  if (!lines.length) return;
  const transcript = lines.join("\n");
  let summary = "(요약 실패)";
  try {
    const r = await fetch("https://api.x.ai/v1/chat/completions", {
      method: "POST",
      headers: { Authorization: `Bearer ${XAI}`, "Content-Type": "application/json" },
      body: JSON.stringify({
        model: MODEL,
        messages: [
          { role: "system", content: "전화 통화 기록을 한국어로 요약해. 형식: 발신자/용건/요청사항/연락처/후속조치, 각 1줄." },
          { role: "user", content: transcript },
        ],
      }),
    });
    const j: any = await r.json();
    summary = j.choices?.[0]?.message?.content || JSON.stringify(j).slice(0, 300);
  } catch (e) { console.error(e); }
  const mins = ((Date.now() - startedAt.getTime()) / 60000).toFixed(1);
  const text = `📞 통화 종료 (${mins}분)\n\n🧾 요약\n${summary}\n\n💬 원문\n${transcript}`;
  for (let i = 0; i < text.length; i += 4000) {   // 텔레그램 4096자 제한
    await fetch(`https://api.telegram.org/bot${TG}/sendMessage`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ chat_id: CHAT, text: text.slice(i, i + 4000) }),
    });
  }
}

index.ts에 연결할 3군데:

// (1) 맨 위
import { sendReport } from "./report";

// (2) app.ws("/media-stream/:callId" ... 안, 맨 앞
const lines: string[] = [];
const startedAt = new Date();
let botBuf = "";

// (3) xaiWs.on('message') 안의 분기에 추가
//   'response.output_audio_transcript.delta' → botBuf += message.delta;
//   'response.done' → if (botBuf) { lines.push("그록: " + botBuf); botBuf = ""; }
//   'conversation.item.input_audio_transcription.completed'
//        → lines.push("상대: " + message.transcript);

// (4) ws.on("close") 안, xaiWs.close() 다음
sendReport(lines, startedAt);
미확인 요약용 모델 이름(grok-4-fast-non-reasoning)은 콘솔 Models에서 실제 이름 확인 후 .env의 XAI_TEXT_MODEL로 바꾸세요. 상대방 말 받아쓰기 이벤트는 예제 코드에 있지만, 안 나오면 session.update에 받아쓰기 설정이 필요할 수 있어요(아래 문제 해결).

6. 시험 체크리스트

  • ☐ /health 가 ok
  • ☐ 내 폰(체험 계정이면 인증한 번호)으로 Twilio 번호에 국제전화
  • ☐ 체험 계정 안내 멘트 → 아무 키 누르기 → 그록 인사 들림
  • ☐ 말 끊고 끼어들어도 그록이 멈추는지
  • ☐ 끊고 10초 안에 텔레그램에 요약+원문 도착
  • ☐ 터미널 1 로그에 User: "..." 줄이 찍히는지

8. 체험(Trial) 계정 주의

  • ⚠️ 인증한 전화번호(Verified Caller IDs)에서 건 전화만 받아요. 다른 사람이 걸면 안 됩니다.
